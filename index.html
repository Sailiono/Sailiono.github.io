01一台 RTK 基站

dpiny

一台基站，不只是一块 GNSS 模块。

UM982 输出差分数据，STM32 管配置、状态和诊断。隔离供电、两路 RS-422、USB 调试口，都要在同一台设备里工作。

从设备结构读起仓库

代码 / 固件 / 台架记录

02飞行估计算法

Aerakia

同一段输入，反复跑算法。

把 Mahony、ESKF 等算法放到主机上，用统一输入和回放检查修改。先把能在电脑上发现的问题找出来，再谈硬件和实飞。

看算法怎么检查仓库

公开部分是算法与主机验证，不是完整飞控。

03隔离接口与分析工具

SBUS–RS-422

换接口之前，先问数据变没变。

做隔离电平转换硬件，也做浏览器分析器。用输入输出采集比较字节和时序；测试条件和采样精度，都留在报告里。

01

先看 README

先确认这个仓库放什么、不放什么。比如 Aerakia 只放算法与主机验证，不能当完整飞控工程来读。

02

带着一个问题往下找

想看设备怎么接，就读 dpiny；想看故障怎么查，USB 复位恢复笔记比一页工具清单更直接。

03

要复用，再看运行条件

算法可以先在主机上跑；涉及板子、电气接口和相机的部分，还是要按自己的硬件重新检查。
