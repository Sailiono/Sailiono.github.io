01 / 项目

项目概览

涵盖 GNSS 设备、估计算法、隔离接口与 Linux 相机。 各项目列出实现内容、公开资料及当前进展。

01GNSS / RTK 基站

dpiny

RTK 基站硬件与固件

基于 STM32F407 与 UM982，集成隔离供电、双路 RS-422 和 USB CDC。固件负责模块配置、状态监测与故障诊断，配套 RTCM 检查及台架测试工具。

02飞行估计算法

Aerakia

飞行估计算法与主机验证

采用可移植 C99 实现 Mahony、ESKF 等估计算法，以统一输入约定、确定性场景和数据回放开展主机侧验证。

查看算法与验证仓库

公开范围：算法模块与主机侧验证，非完整飞控固件。

03隔离接口 / 数据分析

SBUS–RS-422

SBUS–RS-422 隔离透明桥

隔离与电平转换硬件配套浏览器分析器，用于采集数据解码及输入输出对比。报告区分内容一致性与时序测量，并说明采样分辨率及适用条件。

04Linux 相机 / 在研

Splicia

Linux 相机平台调试

围绕 IMX296 相机，记录 Linux 平台的设备发现、媒体拓扑与 RAW 输出调试。视觉算法、运动控制和下一阶段 UI 仍处于规划或设计阶段。
